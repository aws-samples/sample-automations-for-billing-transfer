# Support

This project is a sample automation for AWS Billing Transfer functionality. It is provided as-is without warranty.

## Getting Help

### Documentation

- Review the [README.md](README.md) for setup and usage instructions
- Check the [CONTRIBUTING.md](CONTRIBUTING.md) for development guidelines
- See the [CHANGELOG.md](CHANGELOG.md) for recent changes

### Issues

If you encounter a bug or have a feature request:

1. Search existing [issues](../../issues) to see if it has already been reported
2. If not, create a new issue with:
   - A clear description of the problem or feature
   - Steps to reproduce (for bugs)
   - Expected vs actual behavior
   - Environment details (AWS region, Node.js version, etc.)

### AWS Support

For issues related to AWS services (Organizations, Billing Conductor, Cost and Usage Reports):

- Contact [AWS Support](https://aws.amazon.com/support/) through your AWS account
- Review [AWS Documentation](https://docs.aws.amazon.com/) for service-specific guidance
